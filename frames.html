Кадры для видео

Правый клик по картинке → «Сохранить изображение как…». Первая загрузка занимает 10–20 секунд: кадр рисуется заново. Дальше отдаётся из кэша мгновенно.

Кадр A — начальный, читает книгу

Открыть оригинал Скопировать ссылку

Сохрани как frame-a-reading.jpg

Кадр B — конечный, смотрит на вошедшего

Открыть оригинал Скопировать ссылку

Сохрани как frame-b-looking.jpg

Промпт для сервиса

Если сервис принимает два кадра — ставь A стартовым, B конечным. Если только один — бери A, движение задаст промпт. Длительность 4–5 секунд, вертикаль, звук выключить, камера статична.
