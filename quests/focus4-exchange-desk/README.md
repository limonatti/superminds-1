# The Exchange Desk

Focus 4 **Second Edition**, **Unit 1.7 Use of English: Register**, Student’s Book pp. 12–13, B2. The entry follows page 13 and appears at the top of Unit 1.

Three stations, six original challenges and 23 checked responses. Learners match formal captions to illustrated exchange activities, link everyday and formal verbs, interpret passive constructions, build indirect questions and select suitable invitations. They then write two separate messages about the same event for different audiences, using explicit criteria without an automatic language grade.

The four generated scenes supply evidence for Challenge 1 and context for the final messages. Exact generation prompt: `assets/image-prompts.md`. This subsection assigns no separate recording, so the quest does not claim an audio task or add unrelated audio. No synthetic speech is used.
