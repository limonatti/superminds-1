# Focus 1 · Second Edition

Original Student’s Book (142 pages), Workbook (printed pp. 0–143), and Word Store (17 printed pages), from the owner-provided Second Edition PDFs. Intro + eight units, reference sections and video worksheets are retained. Workbook duplicates and the Word Store booklet order are normalized to printed page numbers.

The reader uses Focus-specific `source-view.js`, `activity.js` and `activity.css`. Each task has explicit fields and interaction metadata; the browser does not infer or reposition answer overlays. The 1,358 printed tasks include 1,058 automatically checked activities. Choice, matching, word banks, multiple selection, word/letter tiles, a word-search grid, oral cards and writing plans have distinct controls. All 1,358 tasks have a click path. Genuine composition tasks retain a text area; personal speaking does not require typing. Open-ended work remains teacher reviewed. A mixed task can record its personal part as completed orally.

Complete original pages preserve all printed text and pictures, with independent scrolling, adjustable scale and a whole-page fit. Opening an exercise focuses its position without cropping the page. Mobile tabs switch between the original and answers. Top previous/next buttons cover all exercises in the current book. Word Store pages, continued columns and reading spreads remain available with their tasks. Answer changes retain prior saved responses rather than silently interpreting them against new fields. Nineteen obsolete OCR-generated links remain usable for existing homework; they are excluded from new exercise lists.

Included media: 163 original human-recorded Student’s Book audio tracks, plus 39 supplied transcripts extracted from the Teacher’s Book. Playback, repeat and transcript controls are attached to the corresponding activities. No speech synthesis is used. The 403 source resources include teacher/photocopiable books, lesson/video plans, tests and word lists (with their own audio). The video catalogue covers all 37 main Second Edition video numbers plus 14 Person A/B role-play versions (51 links): 49 YouTube links, checked through actual embedded playback on 2026-11-11, and exact course copies of videos 20 (The Chinese school experiment) and 28 (A special breakfast) on RUTUBE. The two RUTUBE players and public metadata were verified, including stream availability and duration. Players load on request without autoplay, support role switching/restart/fullscreen, link to the hosting platform and stop when closed. Sixteen original video transcripts are extracted from the Teacher’s Book. All 51 players passed muted start/middle/end playback, pause and removal-on-close checks. Video bindings are exercise-specific. English captions, original scripts and worksheet keys were compared; the two RUTUBE copies have no independent online captions, so their semantic check uses the supplied scripts and course identity. Ambiguous questions, wrong audio/video bindings and printed time offsets are corrected in the interactive instructions. See `audit/video-review.json` for methods, results and limitations. This is not a claim of watching every video in full.

Responses are isolated per account under `focus-1`, synchronized through the existing coursework API, and retained locally on network failure. Homework uses `focusExercises` metadata, immutable submitted snapshots and existing teacher reports. LiveCourse synchronizes pages, tasks and student responses with the room. The original authored practice pages remain archived in `legacy/`; their prior data is not migrated or deleted. The current reader does not link to that older practice because it contains synthetic audio. All audio in the rebuilt reader uses the supplied human recordings.

## Rebuild and validate

With Python 3 and Pillow installed, run `python3 focus-1-active-teach/build.py`. This consumes the checked-in OCR, teacher spans, answer keys and page images. `compile-wordstore.py`, `compile-activities.py` and `audit-sources.py` are invoked automatically. Reviewed answer/interaction corrections live in `data/activity-overrides.json`. Workbook anchors and columns were rechecked using per-column OCR; `data/source-text-bounds.json` contains student-facing PDF text bounds and Workbook OCR word bounds. Teacher margin notes and answer marks are excluded from those display bounds. `audit/textbook-review.json` records the review scope, changed answer models, restored tasks, per-exercise formats and limitations. `audit/coverage.json` is the final coverage; `audit/build.json` describes the initial SB/WB compilation. Source PDF hashes are in `audit/sources.json`.

Run `node tests/focus-1.cjs`, `node tests/focus-1-video-content.cjs` and `python3 check.py`. For browser checks, serve the repository on localhost:8788 and run `node tests/focus-1-browser.cjs`, `node tests/focus-1-activities-browser.cjs` `node tests/focus-1-all-exercises.cjs` and `node tests/focus-1-interactive-regressions.cjs` with Playwright and Chrome installed; `PLAYWRIGHT_MODULE` and `FOCUS_TEST_BASE` can override the module location and server URL. Browser tests mock accounts and never write to Supabase. Chrome is muted, and any test playback is forced to muted/zero volume before Play. The exhaustive test opens every task at 1440 px and 390 px, checks field counts, correct/incorrect marking, reachable controls and overflow; reviewed semantic fixtures are checked separately. They cover grading, local restore, cloud failure/retry, homework snapshots, teacher assignment, audio, mobile layout and the live iframe adapter.

After rebuilding generated JS, refresh the content hashes in `focus-homework.js` and this reader’s `index.html`; root page dependencies use `stamp.py`. Root `focus-1-u*.html` pages redirect to this reader, preserving query parameters. Do not rerun the old Focus page generator over those redirects.
